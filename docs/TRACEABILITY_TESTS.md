# Traceability Matrix: Business Rules & System Guards to Tests

This document maps every business rule (**BR-01 through BR-40**) and non-bypassable system guard (**G-01 through G-18**) to its automated test coverage across database (pgTAP), backend unit/integration (pytest), and frontend unit/E2E (Vitest & Playwright).

> [!IMPORTANT]
> **Completeness Invariant:** Every rule and guard MUST be tested. An automated test (`test_traceability_rules_and_guards.py`) verifies that no ID is missing from this document.
